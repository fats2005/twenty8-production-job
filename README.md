# CareerApply updated multi-step application

Updated from `fats2005/twenty8-production`.

## New features
- One question per page/step.
- Continue and Back navigation.
- Application progress percentage.
- Application deadline and countdown.
- Settings icon in the top-right corner.
- Settings drawer with Save Draft, Resume, Theme, Report a Problem, Seek Assistance, Feedback and Log Out.
- Local draft persistence using browser localStorage.
- Responsive mobile interface.

## Important
This is still a front-end application. Log out, draft saving and progress are browser-side features. Real applicant accounts, secure CV storage, authentication and database submission require a backend.

The existing repository is public and contains `index.html`, `script.js`, `style.css`, `.gitignore` and `README.md`.
